# StudyPulse

Telegram-бот для трекинга учебных дедлайнов и привычек студентов.

> Статус: в разработке (прототип).

## Цель

Студенты теряют из виду дедлайны и не могут выработать регулярные учебные привычки. StudyPulse собирает дедлайны и привычки в одном месте, в привычном мессенджере, и показывает наглядную статистику регулярности.

**Целевая аудитория:** студенты ЮУрГУ, в перспективе студенты других вузов.

## Ключевые функции

- Учёт учебных дедлайнов с напоминаниями
- Чеклисты и трекинг учебных привычек
- Простая статистика выполнения (регулярность, серии)
- Платная подписка (199 ₽/мес) для расширенных возможностей (планируется)
