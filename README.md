# StudyPulse

Telegram-бот для трекинга учебных дедлайнов и привычек студентов.

## Цель
Помочь студентам не пропускать дедлайны и выстраивать учебные привычки.

## Ключевые функции
- добавление дедлайнов и напоминания о них;
- трекинг привычек;
- статистика выполнения.
